# 字体来源与授权

本目录下的 `.woff2` 是程序生成的子集字体，均来自 **SIL Open Font License 1.1**（见 `OFL.txt`）的开源字体，
可免费商用。仅用于大屏歌词展示，未做任何字形修改，只做了字符子集化（见 `client/scripts/build-fonts.sh`）。
